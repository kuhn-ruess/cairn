Hand tickets to their Zammad owner — after matching the agents

A run files each new ticket under the person who owns it in Zammad, as the roster stands when the run starts — so everything imported before the agents were matched went to {{ team.admin.display_name or team.admin.username if team.admin }} as the fallback, and no later run moves it, because an imported ticket is recognised and never re-filed. This is the one-off that catches up: tickets still sitting where the import put them go to the account their Zammad owner maps to, into that person's own target project. Anything somebody has filed into a project since stays where it is.
