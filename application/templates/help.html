Keyboard shortcuts

Hover or click on any task row to start. Shortcuts that act on a selection need at least one selected task.

Selection

{{ kbd(["⌘", "click"]) }} / {{ kbd(["Ctrl", "click"]) }}

{{ kbd(["Shift", "click"]) }}
Select a range from the last clicked row
{{ kbd(["⌘", "A"]) }} / {{ kbd(["Ctrl", "A"]) }}
Select all visible items
{{ kbd(["Esc"]) }}

GTD status legend

Inbox
Captured but untriaged — default for new + imported tasks.
NEXT
Actively engaging — set explicitly via N.
Waiting
Blocked on someone / something external.
Someday
Maybe later — out of view by default.
Done / Dropped
Completed or abandoned.

A Defer date in the future blocks the task regardless of status — it greys out in lists and lives in the Scheduled perspective until the date hits.
