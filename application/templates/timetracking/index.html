Import from mite

Pulls customers and projects (with rates and budgets) into {{ team.name }} — and, if you ask for it, the whole time history. Repeatable either way: everything carries its mite id, so a second run updates what changed and adds only what is new, and a projects-only run can be widened to a full import later. The API key is used for this request only and never stored.

A large account can take a while — for years of history cairn import-mite on the server is the better route.
