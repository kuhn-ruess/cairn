Where do I find the iCal URL?
  • Google Calendar: open settings → pick the calendar in the sidebar → scroll to Integrate calendar → copy Secret address in iCal format.
  • iCloud Calendar: right-click the calendar → Share → enable Public Calendar → copy the URL (replace webcal:// with https://).
  • Outlook.com: Settings → Calendar → Shared calendars → publish → copy the ICS link.

Which URL do I paste? (Nextcloud)
  • You don't need one: paste https://cloud.example.com and all your calendars are connected at once. Submitting the same address again later picks up any you've added since.
  • For a single calendar: Nextcloud → Calendar app → hover a calendar → ⋯ → Copy private link. That link is the collection URL to paste above.
  • Create an app password under Nextcloud → Settings → Security → Devices & sessions, and use it instead of your login password.
